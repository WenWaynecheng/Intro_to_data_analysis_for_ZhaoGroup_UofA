# Intro_to_data_analysis_for_ZhaoGroup_UofA
first made by Wayne Cheng, Master student 2024 - (present).

This repository contains the Python/Jupyter Notebooks used by me to process and analyze liquid chromatography-mass spectrometry (LCMS) data, with a specific focus on the chemical profiling of freshly emitted smoke from biomass burning.

This was not intended for the public but shared with group members who might need data analysis

## 🗂️ Planned Structure
* `sample_data/`
  * `Wood burning`- the initial dataset that was collected for testing

* `python/` python codes for processing mass spec or other generic data.
  * `01_introduction.ipynb`

* `Tutorial/` This folder contains other stuff like softwares.
  * `1_MSConvert.ipynb` 

* `requirements.txt` - List of required Python dependencies.
